## Trạng thái dự án

| Status | Ý nghĩa |
|--------|----------|
| 🟢 **Mới ký** | Đã ký HĐ, chưa mobilize |
| 🔵 **Đang thi công** | Đang thực hiện đúng tiến độ |
| 🟡 **Behind schedule** | Chậm hơn kế hoạch |
| 🟠 **Đang nghiệm thu** | Thi công xong, đang làm hồ sơ NT |
| 🔴 **Rủi ro** | Có vấn đề pháp lý/thanh toán/kyç hạn |
| ✅ **Completed** | Đã thanh quyết toán xong |
| 🛡️ **Bảo hành** | Trong thời gian bảo hành |

## Suggested Google Sheets structure

Tạo sheet với các tab:
1. **Pipeline** — Tổng hợp tất cả dự án (bảng trên)
2. **Monthly** — Doanh thu + công nợ theo tháng
3. **Timeline** — Gantt chart đơn giản (tuần)
4. **Risks** — Rủi ro + action items
5. **Contacts** — Đối tác, CDT, tư vấn, TVGS
