# Checklist nghiệm thu hệ thống PCCC — Theo TCVN 3905:2013

## 1. Hệ thống báo cháy tự động (TCVN 5738:2021)

### Thi công
- [ ] Tuyến cáp FPH/FPLP đi ống EMC, đúng khoảng cách
- [ ] Đầu báo khói: vị trí theo bản vẽ, bán kính覆盖 ≤ 60m² (trần phẳng) / ≤ 30m² (có rào chắn)
- [ ] Đầu báo nhiệt: bán kính ≤ 20m², khoảng cách ≤ 9m
- [ ] Chuông báo cháy: ≥ 75dB tại 1m, vị trí thoát hiểm
- [ ] Nút nhấn thủ công: cao 1.2-1.5m, cách cửa thoát hiểm ≤ 5m
- [ ] Module cách ly: mỗi vòng ≤ 32 thiết bị
- [ ] Tủ trung tâm: UPS backup ≥ 24h, hiển thị zone/vùng

### Nghiệm thu
- [ ] Test từng đầu báo (khói + nhiệt) — phản hồi tại tủ ≤ 10 giây
- [ ] Test từng nút nhấn thủ công
- [ ] Test chuông + siren toàn bộ
- [ ] Test mất điện primary → UPS tự động
- [ ] Kiểm tra số lượng thiết bị so với bản vẽ
- [ ] Chụp ảnh từng vị trí thiết bị đã lắp
- [ ] Biên bản nghiệm thu che khuất (ống âm sàn/âm tường) ký TVGS

---

## 2. Hệ thống sprinkler / chữa cháy nước (TCVN 7336:2021)

### Thi công
- [ ] Ống thép mạ kẽm, nối ren hoặc grooved, đúng DN
- [ ] Sprinkler head: khoảng cách theo bản vẽ, khu vực che khuất bổ sung
- [ ] Van cảnh báo (alarm valve / flow switch) từng zone
- [ ] Bơm chữa cháy: Q, H đúng thiết kế, test run ≥ 2h
- [ ] Bể chứa nước: dung tích ≥ yêu cầu thiết kế
- [ ] Áp suất test: 1.5× áp suất làm việc, giữ ≥ 2h, không rỉ
- [ ] Xả nước thử từng đầu sprinkler

### Nghiệm thu
- [ ] Hydrostatic test biên bản — TVGS ký
- [ ] Flush đường ống chính trước lắp sprinkler head
- [ ] Test bơm: chạy trực tiếp + chạy qua biến tần
- [ ] Test flow switch → cảnh báo tại tủ báo cháy
- [ ] Kiểm tra paint mask sprinkler head (không được sơn phủ)
- [ ] Biên bản nghiệm thu che khuất (ống âm trần)

---

## 3. Hệ thống gas suppression — FM200 / CO2 (NFPA 2001)

### Thi công
- [ ] Bình gas: dung tích + khối lượng theo thiết kế
- [ ] Nozzle: vị trí + góc phun đúng bản vẽ
- [ ] Tuyến ống: chống ăn mòn, nối đúng tiêu chuẩn
- [ ] Panel điều khiển: liên động với tủ báo cháy
- [ ] Cảm biến khí: vị trí + ngưỡng cảnh báo
- [ ] Cửa thoát hiểm tự động mở khi xả gas
- [ ] Biển cảnh báo "Khu vực gas suppression"

### Nghiệm thu
- [ ] Kiểm tra khối lượng gas thực tế vs thiết kế
- [ ] Test xả thử (nếu yêu cầu) — TVGS + PCCC quận giám sát
- [ ] Test liên động: báo cháy → đóng cửa → xả gas → cảnh báo
- [ ] Test abort switch (dừng xả khẩn cấp)
- [ ] Kiểm tra phòng kín: tính toán nồng độ thiết kế đúng thể tích phòng

---

## 4. Đèn thoát nạn / Exit Sign

### Thi công
- [ ] Đèn exit: vị trí trên cửa thoát hiểm, cao ≥ 2m
- [ ] Bảng chỉ dẫn: mũi tên hướng thoát hiểm
- [ ] Pin backup: ≥ 90 phút khi mất điện (theo TCVN 3890)
- [ ] Cáp cấp nguồn: riêng, không共用 với hệ thống khác

### Nghiệm thu
- [ ] Test mất điện → đèn tự sáng
- [ ] Đo độ sáng ≥ 50 lux tại mặt sàn (đèn chiếu sáng thoát hiểm)
- [ ] Kiểm tra pin backup ≥ 90 phút
- [ ] Kiểm tra vị trí + số lượng so với bản vẽ đã duyệt

---

## 5. Loa PA / Thông báo khẩn cấp (EVAC)

### Thi công
- [ ] Loa: công suất + vị trí đúng thiết kế
- [ ] Cáp 100V line, shielded nếu gần cáp động lực
- [ ] Khoảng cách tuyến PA vs động lực: ≥ 300mm
- [ ] Amplifier: dự phòng (N+1 hoặc 2× capacity)
- [ ] Mic khẩn cấp: ưu tiên cao nhất (ducking all other audio)

### Nghiệm thu
- [ ] Đo SPL: ≥ 65dB hoặc +10dB above ambient (theo TCVN 6761)
- [ ] Test intelligibility (STI ≥ 0.5 hoặc STIPA ≥ 0.5)
- [ ] Test mic khẩn cấp → tất cả loa phát thông báo
- [ ] Test phân zone: thông báo từng khu vực riêng biệt

---

## 6. Hồ sơ pháp lý chung (TT 06/2021/TT-BXD)

### Bắt buộc cho mọi dự án PCCC
- [ ] Bản vẽ thi công đã duyệt (shop drawing)
- [ ] Biên bản nghiệm thu che khuất (âm sàn, âm tường, âm trần)
- [ ] Biên bản nghiệm thu thiết bị (TVGS ký)
- [ ] Certificate of Conformity (C/Q) cho thiết bị PCCC
- [ ] Hồ sơ hoàn công (as-built drawing)
- [ ] Test report hệ thống PCCC (có PCCC quận/CS PCCC chứng kiến)
- [ ] Giấy chứng nhận kiểm định PCCC (cơ quan có thẩm quyền)

### Lưu ý quan trọng
- **Nghiệm thu che khuất PHẢI có TVGS ký trước khi lấp** — không ngoại lệ
- **Thiếu hồ sơ = không thanh quyết toán** theo đúng quy định
- **Test PCCC phải có CS PCCC quận tham gia** — liên hệ trước 7 ngày
